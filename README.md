# Bird corporation projects

​🚁 Bird Robotics — Open Source Ecosystem & Telemetry Analysis
​Bird Robotics — это открытая инженерная экосистема беспилотных летательных аппаратов, объединяющая разработку экспериментального дрона с управляемым вектором тяги и создание бюджетного FPV-квадрокоптера.
​Проект разработан в рамках двухпараллельной стратегии («2-в-1») для проверки нестандартных аэродинамических решений и математических моделей стабилизации.
​📌 Ключевые направления разработки
​1. Bird Bicopter (Физический прототип)
​Конструкция: Двухмоторный аппарат с управляемым вектором тяги. Отклонение потока воздуха осуществляется поворотными створками в аэродинамических тубусах (135 мм) на сервоприводах MG90S.
​Вычислительное ядро: Микроконтроллер ESP32 (32-bit Dual Core, 240 МГц). Первое ядро выделено под ПИД-петлю (500 Гц), второе — под Wi-Fi телеметрию.
​Математика и фильтрация: Алгоритм ориентации Madgwick AHRS (250 Гц) и ПИД-компенсация с защитой от насыщения (Anti-windup).
​Характеристики: Взлетная масса — 500\text{ г}, тяговооруженность — 1.8:1, нейтральное висение при 52\% газа.
​2. Bird Quadrocopter (CAD-проектирование)
​Конструкция: Классический FPV-квадрокоптер на раме из ударопрочного композита PETG-CF (пластик, армированный угловолокном).
​Цель: Полный комплект 3D-моделей (STEP/STL) и точный расчет массы до миллиметра и грамма при бюджете до 10\ 000\text{ руб.}
​🛠️ Стек технологий и железо
​Hardware: ESP32, MPU6050 (IMU), MT2204 2300KV, ESC 30A, MG90S, Repka Pi (пульт), 3S Li-Ion 18650 (20\text{A}+).
​Software: C++ (кастомная прошивка полетного контроллера), Madgwick AHRS, Python / FreeCAD / КОМПАС-3D.
​Связь и видео: Wi-Fi управления с Repka Pi на ESP32, передача видеопотока с ESP32-CAM.
​🗺️ Дорожная карта (Timeline)
​Стенд & Маджвик: Сборка балансировочного стенда, считывание углов Roll/Pitch/Yaw.
​ПИД-настройка: Программная отладка алгоритмов стабилизации на столе.
​Первый полет: Тестовые висения Бикоптера на привязи.
​CAD & Сборка: Финализация 3D-модели квадрокоптера и физическая сборка.
